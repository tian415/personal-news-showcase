# 设计与限制

采集与解析 → 质量和时间过滤 → 选择与摘要 → 网页/邮件渲染 → 投递状态 → 反馈导入。

公开内容与私有状态分别存储。真实部署工作流仅作为 examples 供阅读，保留其私有仓库保护；展示仓库不配置生产 Secrets，也不启用定时发送。

`legacy` 是基线选择器；事件级和分层策略保留为影子评估。v4 实验区分事件重要程度与新增信息价值，合并同一事件的进展，并保留来源与证据。这些是已实现的实验逻辑，不代表已上线或已验证新闻价值。

部分质量/成本字段沿用占位值，不能作为模型质量、实际费用或节约时间的证明。真实来源覆盖、语义准确性与持续使用收益仍需实测。

`experiments/daily_writer` 的历史语料加载入口不属于公共演示，相关本地语料不随包提供。通用接口由合成测试覆盖。
